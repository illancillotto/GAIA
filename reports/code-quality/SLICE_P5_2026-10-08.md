## Behavioral invariants

- Anonymous users redirect to login; module-denied users never load subject APIs.
- Actual `UtenzeModulePage` / `AnagraficaModulePage` gates remain in the test tree.
- Subject fetch is keyed by route ID and token; loading precedes data rendering.
- Subject errors hide edit controls and distinguish Error versus opaque failures.
- Person/company identity populates the breadcrumb and appropriate form fields.
- Default mode is read-only; confirmation is required before enabling editing.
- Cancel/terminate editing does not send a mutation.
- Save sends edited fields with null normalization, then adopts the response
  subject, displays success and returns to read-only.
- Failed save retains edit mode and data; it reports errors without success text.
- Tab changes delegate token/subject ID and irrigation utenza ID to child sections.
- Back navigation targets `/utenze/import#utenze-soggetti`; embedded mode omits it.
- Merged subjects and company subjects do not render ANPR actions.
- NAS errors retain the subject and provide a fallback status.
- Payment permission errors are suppressed; operational failure marks unavailable
  payment notices without blocking the subject.
