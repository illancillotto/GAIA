## Approved responsibility and equivalence

The Coordinator approved the pure collaborator filter model before runtime
editing. It owns monthly row selection only: available collaborator facts and
the nine existing filter values. It accepts no setters, React lifecycle,
API clients, editor state, modal context or aggregation commands.

The meaningful simplification replaces four repeated early-return branches
with an ordered collection of active operational keys and one `every`
predicate. Profile classification moves unchanged into the same model because
both row selection and existing profile counts need it; this relocation is
neutral and has no independent improvement claim.

### Invariants

- Seven stages retain their order: present IDs, dominant schedule, contract
  profile, monthly anomalies, daily focus, operational totals, search; then
  name ordering through the same `localeCompare` semantics.
- Operational keys remain KM, travel, overtime, availability. Disabled keys
  are not read; the first rejecting key short-circuits later keys.
- The predicate is `!(value <= 0)`, preserving NaN rather than converting it
  into an unrequested positive-number requirement. Zero, negative values and
  negative infinity reject; NaN and positive infinity retain original behavior.
- Empty active filters retain rows even when their monthly totals are absent.
  Presence and earlier stages still exclude rows before totals are accessed.
- Daily focus uses the same anomaly/request maps and remains fail-closed when
  the selected day no longer has a set after validation.
- Search retains trimming, lowercase conversion, employee-code/name/company
  inputs, company fallback and evaluation of the company label even when the
  normalized search is empty.
- Row references, collaborator input order and maps remain untouched; the
  filtered result is sorted separately.
- All memo/effect dependency arrays, React state, deferred search, progressive
  row visibility, API requests, caches, polling, cleanup, validation,
  permissions and modal navigation are unchanged. No JSX changes.
