## Behavioral invariants

- Conversione invariata: `int(str(value).strip())`, clamp minimo zero;
  default zero per chiave assente o `TypeError`/`ValueError`.
- Decimal string, boolean, None, lista e dict invalidi restano zero.
- Stesso ordine: lookup sorgente, controllo stato active, lettura bytes_sent,
  lettura bytes_received, confronto src_ip e poi eventuale dst_ip con le
  proprietà correnti del device.
- Sorgente active: direzione received/sent normale; destinazione coincidente:
  direzione invertita; nessuna coincidenza: entrambi zero.
- Sorgente retired/mancante: direzione received/sent invariata, non conteggiata
  come device sorgente con traffico.
- Counters, top domains/destinations/source devices, timeline, peer,
  tracking, query SQL, stream yield_per, ordinamento e limiti invariati.
- Nessuna mutazione DB, commit/rollback, auth, scanner, rete esterna o API nuova.
- Nessuna fotografia anticipata dell'IP: proprietà dinamiche non vengono
  accorpate in una lettura singola; il controllo race-sensitive resta identico.
